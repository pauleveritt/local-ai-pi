# Keeping a Small Local Model On Track — with Pi

A course teaching how to keep a small local model on track while it does real
Python development under the [Pi agent harness](https://pi.dev), using only
built-in Pi features.

The reader never adopts a technique on faith: each part shows the failure with
recorded telemetry, applies one Pi mechanism, then measures whether it helped.

See the [README](https://github.com/) for the full framing, and
`docs/superpowers/roadmap.md` for how the course is being built.
